Extension types
Three ways this app can show up outside its own page.
Theme app block

UI the merchant drags into a specific spot on a storefront page, from the theme editor's Add block → Apps menu.

Where it appears: inside one section of one template — product, cart, etc.
Example: a star-rating strip placed just under the product title.
Add theme app block
Theme app embed

UI or script that runs globally across the storefront, once the merchant flips it on under Theme settings → App embeds. Off by default after install.

Where it appears: every page — injected into head, body, or the compliance region.
Example: a chat bubble or an announcement bar.
Add theme app embed
Admin UI extension

An action, an inline block, or a print view rendered natively inside Ratio's merchant admin, in a sandboxed component model — no raw DOM access.

Where it appears: order/product pages, the More actions menu, or the Print menu.
Example: "Add to wishlist" in an order's More actions menu.
Add admin UI extension
