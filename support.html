Frequently asked
How long does app review take?
Most submissions get a decision within 48 hours. If your app is rejected, the quality-check feedback appears directly on the app's Overview tab.
Can one organisation have more than one dev store?
Not yet — every organisation gets one dev store for now. Multi-store support is on the way; sit tight and we'll let you know the moment it rolls out.
How do I get access to a client's live store?
From Stores → Collaborations, request access with the store's URL and the 4-digit code the merchant gives you. The merchant approves, narrows, or denies the scopes you asked for.
Does Ratio charge me anything to build or list an app?
No — building and listing apps on Ratio is free. If your app charges merchants, Settings → Payouts has what you've earned and when it's paid out, with the GST breakdown behind each charge.
What kinds of extensions can my app ship?
Three today: a theme app block (merchant places it in a storefront section), a theme app embed (runs globally once the merchant turns it on), and an admin UI extension (an action, block or print view inside Ratio's merchant admin). See the extensions guide.
How do webhooks work?
Two ways: declare topics in your app's manifest (applies on publish or install) or register them at runtime with the Webhooks API (applies immediately). There's no "configure and save" step in the dashboard — an app's Webhooks tab is a read-only view of what's actually active. See the webhooks guide.
Can I create an app from the terminal instead of the browser?
Yes — run npx @ratio/cli create app. It's surfaced right from the Create app dropdown on the Apps page if you'd rather not leave your terminal.
